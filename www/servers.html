Find a server

Community servers that are running IW4x right now. Join opens the game and connects you to the server.

The server list is loaded by a script, which your browser did not run.

You can find the same servers in the game: start IW4x and open Server Browser from the multiplayer menu.

If Join does nothing

Join uses an iw4x:// link, which your system only knows about once IW4x has been started on it. Start IW4x once, then try again.

You can also connect by hand. Open the console in the game with the key above Tab and type connect followed by the address shown under the server name.
